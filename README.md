# ERP_AI

A mock ERP/LMS platform featuring course management, assignment viewing, and file uploads, built with FastAPI and PostgreSQL.

## Prerequisites

- Python 3.11+
- PostgreSQL
- VS Code with Live Server extension

## Setup & Run

### 1. Clone the repository

```bash
git clone <repository-url>
cd ERP_AI
```

### 2. Create and activate a virtual environment

**macOS/Linux**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file in the project root.

Generate your own JWT secret key:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Add the generated key to `.env` along with your database configuration:

```env
JWT_SECRET_KEY=your_generated_secret_here
```

Configure any additional environment variables required by your local database setup.

**Important:** Each developer should generate their own JWT secret. Never commit your `.env` file or share your secret key.

### 5. Start the backend

From the project root, run:

```bash
python -m uvicorn backend.main:app --reload
```

Backend: http://127.0.0.1:8000

Keep the terminal running while using the application.

### 6. Start the frontend

Open `frontend/index.html` using the **Live Server** extension in VS Code.

Keep the backend running while using the frontend.

## Dependencies

Python dependencies are listed in `requirements.txt`.

Ensure `python-multipart` is included for assignment file uploads.

## Notes

- Configure PostgreSQL and the required environment variables before starting the backend.
- Keep `.env` and other files containing credentials out of version control.
- JWT tokens generated by one developer's local backend will not be valid on another developer's backend when their secret keys differ.
